SJF (Shortest Job First)

Non-preemptive

Processes are scheduled in order of ascending burst time. Among processes arriving at the same time, the one with the smallest burst is picked first. SJF minimizes average waiting time for a given set of processes.

1 Sort by arrival time, break ties by burst time
2 Pick the available process with smallest burst
3 Execute fully before scheduling next

Formulas

Completion Time

CT = Start + Burst

Turnaround Time

TAT = CT − Arrival

Waiting Time

WT = TAT − Burst

Avg. Waiting Time

AWT = Σ(WT) / n
